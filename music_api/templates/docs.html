built for the next track.

Музыкальная платформа на Django, которая собирает поиск, чарты, плейлисты и realtime-взаимодействия в одном ASGI-приложении.

01

Features

RubySound объединяет быстрый поиск музыки с интерфейсом, который удобно исследовать и на десктопе, и на мобильном устройстве.

Smart search

Параллельные запросы к Last.fm, TheAudioDB, Deezer и iTunes с автодополнением по артистам.

Personal library

Плейлисты, избранные треки, публичные подборки и превью аудио через WaveSurfer.js.

Live presence

Уведомления, комментарии и статус присутствия работают через Django Channels.

02

Stack

Проект разделён на доменные приложения, shared-шаблоны и frontend-бандл. Инфраструктурные зависимости запускаются рядом с приложением.

03

Backend

Точка входа — music_project: маршрутизация HTTP и WebSocket, настройки окружений и ASGI. Бизнес-логика находится в music_api и users.

music_project/asgi.pyHTTP + AuthMiddlewareStack + URLRouter

Асинхронные view отправляют независимые запросы провайдерам одновременно, а DRF-сериализаторы формируют стабильный контракт ответа.

04

Frontend

Шаблоны Django отвечают за структуру страниц, а Vite собирает vendor-зависимости и TypeScript в единый entry. Bootstrap задаёт сетку, GSAP — переходы, PWA-слой позволяет установить приложение.

TypeScriptViteBootstrap 5GSAPWaveSurfer.jsPWA
05

Security

Защищённые endpoints используют JWT и права DRF; публичные методы объявлены явно. CSRF, secure-cookie настройки production и единый обработчик ошибок закрывают базовые веб-риски.

  • Access/refresh токены и blacklist для отзыва сессий.
  • Проверка владельца для профиля, избранного и личных плейлистов.
  • Backup-операции в Admin доступны только superuser.
  • Секреты и ключи провайдеров приходят из переменных окружения.
06

Docker

Compose поднимает web-приложение, PostgreSQL и Redis; отдельный профиль добавляет Prometheus и Grafana. Healthcheck использует /health/live.

Локальный контурGrafana: localhost:3000 · Prometheus: localhost:9090
07

Backup & Restore

PostgreSQL сохраняется в custom dump с timestamp. Архивами можно управлять через Makefile или backup-центр Django Admin; лимит хранения задаётся BACKUP_KEEP_COUNT.

make db-backup
make db-restore FILE=backups/music_platform_YYYYMMDD-HHMMSS.dump

Load Testing

Сценарий k6 проверяет health, поиск, чарты и публичные плейлисты. Для авторизованных сценариев передайте LOADTEST_USERNAME и LOADTEST_PASSWORD.

make k6-loaddocker-compose.k6.yml · steady traffic profile

Quick Start

Минимальный путь от клонирования до работающего приложения:

  1. 01
    Скопируйте окружение

    Создайте .env и добавьте ключи Last.fm, PostgreSQL и Redis.

  2. 02
    Установите зависимости

    pip install -r requirements.txt и npm ci.

  3. 03
    Запустите сервисы

    docker compose up -d db redis, затем выполните миграции.

13

Run Project

Для разработки можно запускать Django и Vite параллельно одной командой:

npm run start
# app: http://localhost:8000
# docs: http://localhost:8000/docs/

Если нужен только backend, используйте python manage.py runserver.

14

FAQ

Где находится интерактивная API-документация?

Swagger UI и ReDoc доступны через ссылки выше, локально — /api/docs/ и /api/redoc/.

Почему не загружается поиск?

Проверьте ключи музыкальных API, Redis и готовность PostgreSQL через /health/ready.

Как включить тёмную тему?

Используйте плавающую кнопку с иконкой луны/солнца в правом нижнем углу. Выбор сохраняется в браузере.
